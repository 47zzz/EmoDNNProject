# EmoDNNProject
This study aims to investigate scene perception, specifically focusing on emotional and neutral information, using convolutional neural networks (CNNs). Employing representational similarity analysis (RSA), we integrated the behavioral performance of emotional ratings with the CNNs to access the layer- wise visual information (Cichy et al., 2014; Dobs et al., 2023).
